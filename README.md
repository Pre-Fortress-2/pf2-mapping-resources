# Pre-Fortress 2 Mapping Resources

This repository is designed to help map creators streamline their setup with ready-to-use gamemode templates.

---

## What's Included

- **Gamemode Templates**

	- Arena
	- Attack/Defense (single stage, flag, multi stage, triangle)
	- Capture the Flag
	- Control Points (5cp)
	- Domination
	- Invasion Capture the Flag
	- King of the Hill
	- Payload (single stage, multi stage)
	- Reverse Capture the Flag
	- Territorial Control
